# Продвижение CtrlNote

## Суть продукта (одно предложение)

Горячая клавиша → заметка в Obsidian vault за секунды (текст / картинка / голос / рисунок).

## Почему сейчас не растёт

1. Репозиторий **private** — чужие не скачают Release.
2. У v1.0.0 **0 скачиваний** — никто снаружи не знает ссылку.
3. Paint и Android есть локально, но **не в релизе**.
4. Нет публичной страницы с кнопкой «Скачать».

Фичи уже достаточны для первых 50–200 пользователей. Узкое место — **раздача**, не код.
