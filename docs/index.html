CtrlNote

Нажал Ctrl+Alt+N — написал, нарисовал или наговорил — заметка уже в Obsidian.

Скачать для Windows Для Obsidian

Как это работает

  1. 1Укажи папку vault при первом запуске
  2. 2Жми Ctrl+Alt+N из любого окна
  3. 3Текст, картинка из буфера, голос или рисунок ✎
  4. 4Файл .md сразу в нужной папке vault

Бесплатно для личного использования. Вопросы — напиши автору (подставь свой контакт перед публикацией).
